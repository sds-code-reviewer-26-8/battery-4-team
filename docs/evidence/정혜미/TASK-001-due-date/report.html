6남은 이슈 · 확인하지 못한 것

  • 환경 문제(포트 8092 점유)로 검증이 한 번 중단된 뒤 재검증해 통과했다.
  • 계획에 없던 변경(구현자 보고, 타당하다고 판단): 납기 입력칸을 type=text(inputmode=numeric)로 사용(정수 아닌 입력 감지), 오류 문구에 새 클래스 .due-error 사용, 납기 변경 시 지도 애니메이션이 다시 시작됨.
  • 가정: 기본값 가능한 빨리 체크, 초과 기준은 소요 일수 > 납기, 납기는 저장하지 않음.
