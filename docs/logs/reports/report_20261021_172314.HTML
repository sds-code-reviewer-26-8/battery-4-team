★버그수정 결과

  • 재현 → 수정 후: 수정 전에는 주문을 취소하면 삭제된 주문 상세(/orders/{번호})로 이동해 HTTP 500 기본 오류 화면이 열렸다. 수정 후에는 취소 직후 주문 목록(/orders)으로 이동한다(PRD 7장 "취소 직후에는 이전 페이지(주문 목록)로 이동한다"). E2E-033 통과.
  • 원인과 수정: AppController.changeStatus 가 상태 변경 후 항상 redirect:/orders/{id} 로 보냈고, 취소가 성공하면 서비스가 주문을 삭제하므로 이동한 상세가 500 이 되었다. 취소 성공 때만 redirect:/orders 로 이동하게 4줄 수정. 서비스 로직은 바꾸지 않음.
  • 재발 방지 테스트: ① E2E-033 의 test.fail() 2줄 제거 ② JUnit OrderFlowTests.cancelRedirectsToOrderListAndStaleCancelStaysOnDetail 추가.
