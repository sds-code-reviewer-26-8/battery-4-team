## Slice Test가 확인하는 것

| 기능 | 개수 | 확인하는 것 |
|---|:-:|---|
| 고객사 | 7개 | 로그인 없이는 수정 불가(401), 이름·version·로그인 아이디가 서비스로 전달, 거부는 400·충돌은 409, 상세에서 작성자에게만 수정 가능 표시 |
| 필요 납기일 | 14개 | 생략·null은 "가능한 빨리", 정수만 허용(5.5·`"10"`·`true`·범위 밖 큰 수는 서비스 호출 전에 400), 목록·상세의 납기 초과 일수 |
| 회원 가입 | 9개 | 로그인 없이 가입 가능, 오류 응답 모양, 로그인 때 세션 ID 교체, 가입 횟수 제한(한도 초과 429)과 로그인 제한 분리 |
| 공장 운영비 | 4개 | 입력칸에 억 원 단위로 표시, 저장 요청 전달, 오류 이유를 모두 모아 400, 로그인 필요 |
| 저장소 (4개 기능 공통) | 6개 | 고객사·납기·해시 설정·공장 운영비 컬럼이 저장되고 읽힘, 고객사 100자 제한과 아이디 중복 방지가 DB에서도 지켜짐 |

- 운영 코드를 일부러 망가뜨려 보는 변이 시험 7가지(고객사 이름 누락, 납기 실수 허용, 로그인 확인 제거, 횟수 제한 무력화, 세션 ID 미교체, 컬럼 길이 변경, 운영비 단위 오류)를 모두 테스트가 잡아냄
